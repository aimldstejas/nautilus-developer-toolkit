# Frequently Asked Questions

## Which Linux distributions are supported?

Ubuntu is the primary supported platform for Version 1.x. Additional distributions will be tested over time.

## Does the toolkit require Docker?

No. Docker-related features are optional.

## Does it require Ollama?

No. AI integrations are optional.

## Does it require Git?

No. Git features appear only within Git repositories.

## Does it require Python?

Python features appear only when a Python project is detected.

## Is Internet connectivity required?

No. Core functionality is designed to work offline.
