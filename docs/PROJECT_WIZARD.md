# Project Wizard

The Project Wizard automates the creation of development projects.

Supported templates include:

- Basic Python
- Data Science
- Streamlit
- FastAPI
- Docker Compose
- Retrieval-Augmented Generation (RAG)
- AI Agent
- MCP Server

The wizard can:

- initialize Git
- create virtual environments
- create Conda environments
- install dependencies
- launch editors
- start applications
