# Nautilus Developer Toolkit Roadmap

This document describes the planned evolution of the Nautilus Developer Toolkit (NDT).

Roadmaps may change as the project evolves.

---

# Version 1.0

## Goal

Stable productivity extension.

Completed:

- Developer menu
- Git integration
- Docker integration
- Python integration
- Project detection
- Project Wizard
- Local AI integration

---

# Version 1.1

## Goal

Public open-source release.

Planned work:

- Installation scripts
- Uninstall scripts
- Documentation improvements
- Screenshots
- Animated demonstrations
- Automated tests
- Packaging
- Multi-distribution testing

---

# Version 2.0

## Goal

Architectural redesign.

Completed:

- Version 2 utility-extraction phase complete
- Reusable utility modularization under `src/nautilus_developer_toolkit/utils/`
- Compatibility-wrapper preservation in `DeveloperContextMenu` where verified
- Focused utility-test expansion
- Utility-extraction consolidation review

In progress:

- Documentation synchronization for the completed utility-extraction milestone

Next:

- Integration review and merge preparation for the utility-extraction branch

Pending work:

- Configuration system
- Cleaner APIs beyond the completed utility-extraction scope
- Service and orchestration architecture review
- UI-bound workflow evolution
- Production-grade project templates
- Packaging, release, and compatibility work

---

# Version 2.5

## Goal

Plugin ecosystem.

Examples:

- Docker plugin
- Git plugin
- Ollama plugin
- Dify plugin
- Kubernetes plugin
- AWS plugin

Third-party plugins will be supported.

---

# Version 3.0

## Goal

AI-assisted development.

Planned features:

- AI Project Generator
- Repository Chat
- AI Code Review
- Test Generation
- Documentation Generation
- Repository Explanation
- Traceback Analysis
- Log Analysis
- Assisted Refactoring

---

# Long-Term Vision

Transform Nautilus Developer Toolkit into a complete Linux developer platform consisting of:

- Nautilus Extension
- Command Line Interface
- Desktop Application
- VS Code Extension
- PyCharm Plugin
- MCP Server
- Local AI Agent integrations

The Nautilus extension will remain the primary interface while additional components expand the ecosystem.
