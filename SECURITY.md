# Security Policy

## Reporting a Vulnerability

If you discover a security issue in Nautilus Developer Toolkit, please report it privately before creating a public issue.

Please include:

- description of the vulnerability;
- affected version;
- steps to reproduce;
- possible impact;
- suggested mitigation (if known).

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.x | Yes |

## Disclosure

Security issues will be investigated as quickly as practical.

Responsible disclosure is appreciated.
