# Support

If you need help using Nautilus Developer Toolkit:

1. Read the README.
2. Check the documentation in the `docs/` directory.
3. Search existing GitHub Issues.
4. Open a new GitHub Issue if necessary.

When requesting help, include:

- Linux distribution
- Desktop environment
- Nautilus version
- Python version
- Error messages
- Relevant logs
- Steps to reproduce

Clear, reproducible reports help us resolve issues more quickly.
