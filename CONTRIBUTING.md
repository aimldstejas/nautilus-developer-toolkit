# Contributing to Nautilus Developer Toolkit

Thank you for your interest in contributing to the Nautilus Developer Toolkit (NDT).

Our goal is to build a reliable, maintainable, Linux-first developer toolkit that benefits the open-source community.

We welcome contributions of all sizes.

---

# Ways to Contribute

You can contribute by:

- Reporting bugs
- Suggesting new features
- Improving documentation
- Improving compatibility
- Adding project templates
- Improving project detection
- Writing tests
- Reviewing pull requests

---

# Before You Start

Please read:

- README.md
- DEVELOPMENT_GUIDELINES.md

These documents describe the project philosophy and engineering standards.

---

# Development Workflow

Use the following Git workflow.

```
main
↑
develop
↑
feature/my-feature
```

Never develop directly on `main`.

---

# Coding Standards

All contributions should follow:

- PEP 8
- Project architecture
- Existing coding style
- Type hints where practical

Avoid introducing unnecessary complexity.

---

# Pull Requests

A pull request should:

- solve one problem;
- remain reasonably small;
- include documentation updates if needed;
- preserve existing functionality.

---

# Feature Requests

Before implementing a major feature, open a discussion describing:

- motivation;
- proposed design;
- expected benefits;
- possible drawbacks.

This helps avoid duplicated effort.

---

# Bug Reports

A good bug report includes:

- operating system;
- Python version;
- Nautilus version;
- steps to reproduce;
- expected behavior;
- actual behavior;
- screenshots or logs if available.

---

# Documentation

Documentation improvements are always welcome.

Examples include:

- correcting mistakes;
- improving explanations;
- adding screenshots;
- adding tutorials.

---

# Code Reviews

Every contribution may be reviewed for:

- readability;
- maintainability;
- architecture;
- documentation;
- testing.

Requested changes should be addressed before merging.

---

# Community

Please be respectful and constructive.

We want NDT to be welcoming to developers of all experience levels.

Thank you for helping improve Nautilus Developer Toolkit.
